# Словарь — веб-приложение

Веб-версия Android-приложения с идентичной функциональностью.

## Запуск

Вариант 1 — просто открыть файл (работает без сервера, словарь загружается из встроенной копии `data.js`):

    open index.html        # macOS
    start index.html       # Windows
    xdg-open index.html    # Linux

Вариант 2 — через любой статический сервер (колоды загружаются из `decks/`):

    python3 -m http.server 8000
    # затем открыть http://localhost:8000

Никаких зависимостей и сборки не требуется — достаточно современного браузера. При
запуске через HTTPS или localhost веб-версия кэширует оболочку приложения и колоды;
после первого открытия её можно использовать без интернета. При открытии через
`file://` все необходимые файлы уже находятся рядом с приложением.

## Данные

- `decks/english_300.tsv` — источник колод «English 300» (английский → русский) и «Ru-Eng 300» (русский → английский): слово, перевод, транскрипция (IPA)
- `decks/english_100_nouns.tsv` — источник колод «English 100 Nouns» (английский → русский) и «Ru-Eng 100 Существительные» (русский → английский): 100 существительных, переводы и IPA
- `decks/english_100_verbs.tsv` — источник колод «English 100 Verbs» (английский → русский) и «Ru-Eng 100 Глаголы» (русский → английский): 100 глаголов с переводами
- `decks/japanese_100.tsv` — колода «Japanese 100»: 100 частотных японских слов и грамматических форм с русскими переводами и чтением кандзи
- `data.js` — встроенные копии колод для запуска через `file://`
- Прогресс и слова хранятся в `localStorage` браузера

## Функциональность

Идентична Android-приложению: интервальные повторения («Заново»/«Хорошо»),
колоды (создание, переименование, удаление, перетаскивание для изменения порядка,
изучение отдельно), слова
(добавление и редактирование, примеры употребления, транскрипция для английского, удаление,
множественный выбор и массовое удаление), авто-заполнение колод «English 300»,
«English 100 Nouns», «Ru-Eng 100 Существительные», «English 100 Verbs», «Ru-Eng 100 Глаголы» и «Japanese 100» при первом запуске. Японская колода
основана на опубликованном списке частотной устной речи; чтения для кандзи показываются
на карточках. Проверка знаний задаёт до 10 случайных слов из словаря или выбранной
колоды и позволяет проверить перевод выбором из нескольких вариантов.
Итог сохраняется, ошибки можно проверить повторно. Успешные ответы и серия правильных ответов
сохраняются; слово отмечается освоенным после трёх правильных ответов подряд.
Можно выбрать светлую, тёмную или системную тему; выбор сохраняется.
